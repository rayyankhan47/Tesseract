LLM writes semantics, not coordinates
The planner outputs a Blueprint DSL: semantic primitives like platform, walls, gable_roof. A deterministic Java compiler expands these into exact block coordinates. Spatial coherence is enforced by code, not guessed by the model.
Renders the build before placing it
The compiler runs in memory. An isometric PNG is generated from the block ops and sent to Gemini Vision. It critiques the image and returns a structured patch list. The blueprint is revised and recompiled. Nothing touches the world until the loop converges.
Strict state machine, shared data context
Every agent reads and writes a single BuildState object. The Orchestrator drives a state machine with explicit legal transitions. No agent calls another directly. Any failure routes cleanly to FAILED.
